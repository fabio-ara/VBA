# Decisões arquiteturais

Use esta pasta somente para decisões técnicas ou arquiteturais de alto impacto que mereçam registro autônomo.

Não criar um arquivo para cada detalhe. Regras de negócio pertencem a `docs/SPEC.md`; estrutura do Excel pertence a `docs/WORKBOOK.md`; trabalho pendente pertence a GitHub Issues.

Formato sugerido:

- contexto;
- decisão;
- alternativas consideradas;
- consequências;
- data e Issues relacionadas.
