# Ferramentas locais

Esta pasta recebe utilitários que realmente reduzam atrito ou melhorem a capacidade de verificar a automação.

Exemplos que podem ser adicionados conforme a necessidade:

- importação dos fontes para o VBE;
- inventário de workbook via Excel COM;
- validação de tabelas, nomes, UserForms e controles;
- testes em cópia temporária do XLSM;
- captura de diagnóstico;
- migrações estruturais controladas.

Evite construir uma plataforma genérica antes de existir necessidade concreta.
